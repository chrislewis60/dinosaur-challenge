# Background Music Files

This folder contains background music for different game scenes.

## Required Files

Add the following music files to this directory:

### 1. `arcade.mp3` (or .ogg)
- **Scene**: Underground Arcade Room
- **Style**: Upbeat, retro arcade music
- **Suggested**: 8-bit style, synthwave, or classic arcade game music
- **Examples**:
  - Retro arcade game soundtracks
  - Chiptune music
  - Synthwave/retrowave tracks

### 2. `warehouse.mp3` (or .ogg)
- **Scene**: Warehouse Level (Stealth Mission)
- **Style**: Tense, suspenseful, atmospheric
- **Suggested**: Dark ambient, tension music, stealth game OST
- **Examples**:
  - Spy/stealth game music
  - Tension-building soundscapes
  - Industrial ambient tracks

## Finding Royalty-Free Music

Here are some sources for free/royalty-free music:

- **Freesound.org** - Community sound library
- **Incompetech** (by Kevin MacLeod) - Royalty-free music
- **Free Music Archive** - Various genres
- **Purple Planet Music** - Free music for games
- **Bensound** - Royalty-free music tracks

## File Formats

Supported formats:
- `.mp3` (most compatible)
- `.ogg` (good quality, smaller size)
- `.wav` (highest quality, larger size)

## Usage

Once you add the files, they'll automatically play when entering each scene:
- The music will fade in smoothly when the scene loads
- It will loop continuously
- It will fade out when leaving the scene
