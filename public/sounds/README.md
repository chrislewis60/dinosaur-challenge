# Sound Effects Files

This folder contains sound effects for game interactions and events.

## Required Sound Files

Add the following sound effect files to this directory:

### Movement & Interaction
- `footstep.mp3` - **IMPORTANT** Footstep sound (plays every 0.45s while moving with WASD)
- `jump.mp3` - Jump sound effect
- `sit.mp3` - Sitting down sound (chair creak)
- `stand.mp3` - Standing up sound

### UI & Interaction
- `click.mp3` - Button click sound
- `hover.mp3` - Button hover sound (optional, subtle)
- `interact.mp3` - General interaction sound (F key press)

### Mission & Events
- `alarm.mp3` - Guard detection alarm
- `door-lock.mp3` - **IMPORTANT** Lock picking sound (plays in loop while holding F at door)
- `door-open.mp3` - Door unlocking/opening
- `hack.mp3` - Terminal hacking sound (keyboard typing, beeps)
- `success.mp3` - Mission success sound
- `mission-start.mp3` - Mission briefing sound

### Ambient
- `warehouse-ambient.mp3` - Warehouse background ambience (optional)
- `arcade-ambient.mp3` - Arcade room ambience (optional)

## Finding Sound Effects

Free sources for sound effects:
- **Freesound.org** - Large community library
- **Zapsplat.com** - Free sound effects
- **Mixkit.co** - Free game sounds
- **OpenGameArt.org** - Game-focused sounds
- **BBC Sound Effects** - Professional quality

## File Formats

Supported formats:
- `.mp3` (most compatible, recommended)
- `.ogg` (good quality)
- `.wav` (highest quality, larger size)

## Tips

- Keep sound effects short (< 2 seconds for most)
- Normalize volume levels
- Use mono for non-directional sounds
- Compress/optimize file sizes for web
